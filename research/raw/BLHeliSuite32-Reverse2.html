数据解密流程

解密逻辑
原值为A，以4字节为单位
I = ( (A<<4) xor (A>>5) ）+ A = eax

外部密钥设为 B = 0xC6EF3720=ebx 每次在循环开头更新
C = ( (B>>11) & 0x3 ) 这样拿到的C只是一个偏移量

ebp是什么呢？ 应该是个变量基址，从外部传进来的，主要是存储堆栈地址
D = [ebp+C*4-34]的值
E = D + B
设 F = 0x7C00
G = E + F = edx
H = I  xor G

更新基址内容

外部变量 J=0x9E3779B9
local.3 -=H
B -= J = ebx

K = local.3
eax = L = (K<<4) xor (K>>5) + K
M = 3 & B
N = [ebp+M*4-0x34]
O = N + B
O += F
L = L xor O
local.4 -= L 

这样每次计算的内容都存储在local.3和local.4中了
每轮计算结束以后，将他们转存到了另一个地方，然后继续下8个字节计算。
当256字节全部计算完成以后，每8字节去掉前2字节后将其余字节拼在一起，然后形成可读配置
